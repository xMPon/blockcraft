# Security Policy

## Supported Versions

Security fixes target the `main` branch.

## Reporting a Vulnerability

Please do not open a public issue with exploit details.

Use GitHub private vulnerability reporting if it is enabled for the repository.
If that is not available, open a minimal public issue asking for a maintainer
security contact, without including technical details.

Helpful reports include:

- A short impact summary
- Steps to reproduce
- Browser and operating system details
- Any relevant save data or seed, if the issue depends on world state

Maintainers should acknowledge reports as soon as practical, triage severity,
and coordinate a fix before public disclosure.
